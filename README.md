# ⚡ FDE FieldOps Academy v2.5 (PWA & GitHub Pages Repository)

Interactive training platform for transitioning from **Data Engineer** to **Forward Deployed Engineer (FDE)**, complete with Operator Login, 8 Curriculum Pillars (16 Verified Labs), 5 War Room Scenarios, 5 Practice Workbenches, 150 Interview Questions, and 42 Verified YouTube & Official Documentation Resources.

## 📁 Structured Repository Layout
- **index.html** — Modular web app entry point (GitHub Pages, iPhone Home Screen PWA, and Mac Dock app)
- **css/styles.css** — Responsive dark-mode Tactical Telemetry UI stylesheet with iOS safe-area support
- **js/data.js** — Complete curriculum dataset (8 Pillars, 5 War Rooms, 5 Workbenches, 150 Interview Questions, 42 Resource Links)
- **js/app.js** — Operator authentication/profile state engine, deterministic exercise graders, search/filter controller, and Service Worker loader
- **manifest.json** — Progressive Web App (PWA) configuration for standalone full-screen mode on iPhone & Mac
- **sw.js** — Offline-first Service Worker caching all repository assets
- **assets/icon.svg** & **icon.svg** — Vector app icon for iOS Home Screen and macOS Dock
- **fde_academy.html** — Self-contained single-file edition (147 KB) bundling HTML, CSS, and JS in one portable file
